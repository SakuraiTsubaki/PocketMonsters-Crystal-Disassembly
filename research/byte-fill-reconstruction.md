# Crystal `ByteFill` disassembly

The Japanese release `crystal-jp-rev0` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one ROM0 implementation of the same 12-byte routine. The committed RGBDS source reconstructs its split 8-bit countdown, including the zero-length no-op case. Per-release reports retain ROM identity, address and code hash without publishing ROM bytes. Candidate/verified release status is preserved from `research/releases.csv` and is not promoted by this function match.
