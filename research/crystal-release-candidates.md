# Crystal release candidates

This foundation pass records the three distinct retail identities available in the local corpus: the Japanese origin release and English USA/Europe revisions 0 and 1. No official Korean Crystal release is assumed, and no unobserved localized identity is synthesized.

Every entry passed Nintendo logo, header checksum, and global checksum validation with the shared `SakuraiTsubaki/Disassembly` Game Boy ROM inspector. The evidence also preserves the Japanese cartridge header's RAM size code `0x05`, distinct from `0x03` in both English revisions.

All identities remain `candidate`. Valid internal checksums establish structural integrity, not independent canonical provenance. Promotion to `verified` requires corroboration from a trusted independent reference or a reproducible matching build.

No ROM binary or byte extract is included.
