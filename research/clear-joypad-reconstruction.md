# Crystal ClearJoypad

The Japanese release `crystal-jp-rev0` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one structurally verified ROM0 `ClearJoypad` immediately after the joypad interrupt `RETI` placeholder. Per-release evidence records the routine address, both HRAM destinations and code hash without publishing ROM bytes. Korean precedes English where available, and candidate status is preserved.
