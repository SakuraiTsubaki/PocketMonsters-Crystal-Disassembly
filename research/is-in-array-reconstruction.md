# Pocket Monsters Crystal IsInArray

The Japanese release `crystal-jp-rev0` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one ROM0 implementation with the same nineteen-byte code hash. The routine searches the first byte of DE-sized entries, stops at 0xff, returns the index in B, and reports a match through carry. No ROM bytes are published. Korean precedes English where available; release status is unchanged.
