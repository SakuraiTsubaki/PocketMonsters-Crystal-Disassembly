# Pocket Monsters Crystal CompareBytesLong

The Japanese release `crystal-jp-rev0` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one ROM0 implementation with the same fifteen-byte code hash. The routine uses a 16-bit BC count and reports equality through carry. Evidence records release identity and address without ROM bytes. Korean precedes English where available; release status is unchanged.
